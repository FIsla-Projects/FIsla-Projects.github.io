Featured project

CMOS DRAM cell — design, debug, layout

A 1T1C DRAM memory cell taken from a blank schematic through write, read, leakage and refresh behaviour in LTspice, then translated into a fabricable physical layout in KLayout using the open-source SkyWater sky130 process design kit.

  • 1T1Ccell topology
  • sky130PDK used for layout
  • 6+bugs found and resolved
  • 250mVsense margin achieved

01 Design and simulation

Built the storage cell, cross-coupled sense amplifier and reference branch in LTspice, then verified write, read and charge-leakage behaviour against analytical predictions.

02 Debug log

Circuit-level faults never announce themselves. Every one of these was found by reading a waveform that looked wrong, then tracing it back through the netlist.

found

Vdd shorted through the netlist

Supply rail was accidentally tied to a signal node in the generated netlist, collapsing the sense amplifier's operating point.

found

Latch stuck at 1.65V, no gain

The sense amp sat at the mid-rail bias point instead of resolving to a rail. Traced to a missing device model reference and incorrectly sized coupling capacitors.

found

BLB shorted to BL

The complementary bitline was accidentally tied to the true bitline, which destroyed the differential signal the sense amp depends on.

found

Paralleled voltage sources, missing initial condition

Two voltage sources were unintentionally paralleled on the same node, and a missing .ic statement let the storage node swing further than the real device would allow.

resolved

Integrated read result, all fixes applied

With every netlist and initial-condition bug corrected, the full read operation resolves cleanly: BL and BLB separate to a clean 250mV sense margin.

found

Write-0 operation losing the stored level entirely

Writing a 0 was pulling the storage node all the way to ground on every access instead of holding the correct level between word-line pulses.

03 Sense amp as a reusable subcircuit

Verified the sense amplifier in isolation before integrating it, then packaged it as a subcircuit with its own symbol so it could be dropped into the full cell schematic.

04 Verified results

Read-0, read-1, write and charge-leakage behaviour, each checked against the analytical expectation before being marked verified.

05 Physical layout, sky130 PDK

Translated the verified circuit into fabricable geometry in KLayout, working through the sky130 layer stack to build a working transistor and full cell layout.
